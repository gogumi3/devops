
# 4주차 - Linux Shell Script 실습

## 1. 학습 목표
- 리눅스 셸 스크립트의 기본 구조 이해
- 변수와 명령행 인자 사용
- if문을 활용한 조건 처리
- 파일 및 디렉터리 존재 여부 확인

## 2. 주요 실습 파일

### greet.sh - 인자 처리
사용자가 입력한 이름을 받아 인사말을 출력한다.

```bash
bash greet.sh 홍길동
```

`$1`은 첫 번째 인자, `$#`은 인자의 개수를 의미한다.
인자가 없으면 사용법을 안내하고 종료한다.

### var.sh - 변수 활용
USERNAME 변수에 이름을 저장하고, date 명령어로
현재 날짜를 가져와 출력한다.

```bash
bash var.sh
```

`$(date +%Y%m%d)`는 현재 날짜를 YYYYMMDD
형식으로 가져오는 명령어다.

### check.sh - 조건문 활용
입력한 경로가 파일인지, 디렉터리인지,
존재하지 않는지 판단한다.

```bash
bash check.sh greet.sh
```

- `-f`: 일반 파일 여부 확인
- `-d`: 디렉터리 여부 확인
- `-z`: 문자열이 비어 있는지 확인

## 3. 배운 내용
- 변수는 값을 저장하고 재사용하는 데 사용한다.
- `$1`, `$#`으로 명령행 인자를 처리할 수 있다.
- `if`, `elif`, `else`로 조건에 따라 동작을 구분한다.
- 셸 스크립트로 반복 작업을 자동화할 수 있다.

## 4. 실습 소감
이번 실습을 통해 리눅스 명령어를 단순히 실행하는
것을 넘어 여러 명령어를 스크립트로 구성하는
방법을 학습했다. 특히 조건문과 인자를 이용하면
상황에 따라 작업을 자동으로 처리할 수 있다는
점을 이해했다.


## 5. 셸 스크립트 실행 예시 및 결과

### 5.1 greet.sh 실행

사용자가 입력한 이름을 받아 인사말을 출력하는 스크립트이다.

**실행 명령어**
```bash
bash greet.sh 홍길동
```

**예상 출력**
```text
안녕하세요, 홍길동님! (인자 개수: 1)
```

첫 번째 인자인 홍길동을 `$1`로 전달받고,
`$#`을 이용하여 입력된 인자의 개수를 출력한다.

인자를 입력하지 않으면 사용법을 안내하고 종료한다.

### 5.2 var.sh 실행

변수를 이용하여 사용자 이름과 날짜가 포함된 파일명을 출력한다.

**실행 명령어**
```bash
bash var.sh
```

**출력 예시**
```text
이름: 홍길동
파일명: backup_20261019.tar.gz
```

`USERNAME` 변수에 사용자 이름을 저장하고,
`$(date +%Y%m%d)`를 사용하여 현재 날짜를 가져온다.

날짜는 실행하는 날에 따라 달라진다.

### 5.3 check.sh 실행

입력한 경로가 파일인지 디렉터리인지 확인하는 스크립트이다.

**파일 확인**
```bash
bash check.sh greet.sh
```

**예상 출력**
```text
파일
```

**디렉터리 확인**
```bash
bash check.sh .
```

**예상 출력**
```text
디렉터리
```

**존재하지 않는 파일 확인**
```bash
bash check.sh abc.txt
```

**예상 출력**
```text
없음
```

`-f`는 일반 파일 여부를 확인하고,
`-d`는 디렉터리 여부를 확인한다.

### 5.4 실습 정리

이번 실습을 통해 명령행 인자와 변수를 활용하는 방법을 이해하였다.
또한 조건문을 사용하여 파일과 디렉터리의 상태를 확인하는 방법을 학습하였다.
이러한 셸 스크립트 기능은 반복 작업 자동화와 시스템 관리에 활용할 수 있다.
