
# 4주차 - Linux Shell Script 실습

## 1. 학습 목표
- 리눅스 셸 스크립트의 기본 구조 이해
- 변수와 명령행 인자 사용
- if문을 활용한 조건 처리
- 파일 및 디렉터리 존재 여부 확인

## 2. 주요 실습 파일

### greet.sh - 인자 처리
사용자가 입력한 이름을 받아 인사말을 출력한다.

```bash
bash greet.sh 홍길동
```

`$1`은 첫 번째 인자, `$#`은 인자의 개수를 의미한다.
인자가 없으면 사용법을 안내하고 종료한다.

### var.sh - 변수 활용
USERNAME 변수에 이름을 저장하고, date 명령어로
현재 날짜를 가져와 출력한다.

```bash
bash var.sh
```

`$(date +%Y%m%d)`는 현재 날짜를 YYYYMMDD
형식으로 가져오는 명령어다.

### check.sh - 조건문 활용
입력한 경로가 파일인지, 디렉터리인지,
존재하지 않는지 판단한다.

```bash
bash check.sh greet.sh
```

- `-f`: 일반 파일 여부 확인
- `-d`: 디렉터리 여부 확인
- `-z`: 문자열이 비어 있는지 확인

## 3. 배운 내용
- 변수는 값을 저장하고 재사용하는 데 사용한다.
- `$1`, `$#`으로 명령행 인자를 처리할 수 있다.
- `if`, `elif`, `else`로 조건에 따라 동작을 구분한다.
- 셸 스크립트로 반복 작업을 자동화할 수 있다.

## 4. 실습 소감
이번 실습을 통해 리눅스 명령어를 단순히 실행하는
것을 넘어 여러 명령어를 스크립트로 구성하는
방법을 학습했다. 특히 조건문과 인자를 이용하면
상황에 따라 작업을 자동으로 처리할 수 있다는
점을 이해했다.
