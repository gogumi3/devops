## nginx 컨테이너 확인

curl localhost:8091
<h1>Welcome to nginx1</h1>

curl localhost:8092
<h1>Welcome to nginx2</h1>

curl localhost:8093
<h1>Welcome to nginx3</h1>

## 1. 학습 목표

- Docker 이미지와 컨테이너의 개념 이해
- Docker를 이용한 Nginx 웹 서버 실행
- 포트 매핑을 통한 여러 웹 서버 접속
- curl 명령어를 이용한 웹 서버 응답 확인
- Docker 컨테이너 관리 명령어 학습

## 2. 주요 개념

### Docker 이미지와 컨테이너
- Docker 이미지: 프로그램 실행에 필요한 환경과 파일을 담은 실행 템플릿이다.
- Docker 컨테이너: 이미지를 기반으로 실제 실행되는 독립적인 환경이다.
- 하나의 이미지로 여러 개의 컨테이너를 생성할 수 있다.

### 포트 매핑
Docker 컨테이너 내부에서 실행되는 서비스에 외부에서 접근할 수 있도록 호스트와 컨테이너의 포트를 연결하는 기능이다.

이번 실습에서는 8091, 8092, 8093 포트를 통해 각각 다른 Nginx 웹 서버에 접근하였다.

## 3. 주요 Docker 명령어

- `docker ps` : 현재 실행 중인 컨테이너 확인
- `docker ps -a` : 종료된 컨테이너까지 모두 확인
- `docker images` : 다운로드하거나 생성한 이미지 확인
- `docker run` : 이미지를 이용하여 컨테이너 생성 및 실행
- `docker logs` : 컨테이너 실행 로그 확인
- `docker stop` : 실행 중인 컨테이너 중지
- `docker rm` : 중지된 컨테이너 삭제

## 4. 실습 과정 및 결과

Nginx 웹 서버에 각각 다른 포트를 할당하고 curl 명령어를 이용하여 정상적으로 응답하는지 확인하였다.

- 8091 포트: Welcome to nginx1
- 8092 포트: Welcome to nginx2
- 8093 포트: Welcome to nginx3

각 포트에서 서로 다른 응답이 출력되는 것을 확인하였다.

이를 통해 Docker를 사용하면 여러 웹 서버 컨테이너를 독립적으로 실행하고, 포트별로 구분하여 접근할 수 있다는 것을 확인하였다.

## 5. 실습을 통해 배운 내용

- Docker 이미지는 컨테이너를 생성하기 위한 기반이라는 것을 이해하였다.
- 하나의 서버에서도 여러 Docker 컨테이너를 실행할 수 있다는 것을 알게 되었다.
- 포트 매핑을 통해 각 컨테이너의 웹 서비스에 접근할 수 있었다.
- curl 명령어로 브라우저를 사용하지 않고 웹 서버의 HTTP 응답을 확인할 수 있었다.

## 6. 실습 소감

이번 실습을 통해 Docker를 이용하여 여러 개의 Nginx 웹 서버를 실행하고 관리하는 방법을 배웠다. 특히 서로 다른 포트를 사용하면 한 서버에서도 여러 웹 서비스를 구분하여 실행할 수 있다는 점이 인상적이었다. 또한 curl 명령어를 이용하여 웹 서버가 정상적으로 작동하는지 확인하는 방법을 익혔다.
